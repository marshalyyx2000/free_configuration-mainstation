**版本：** 1.2  
**日期：** 2026-11-17  
**依据文档：** 《保信子站免配置技术方案》（20251120；含 **规范版** 附录 A）  
**配套工程：** `免配置/master_sim/sim_master_qt`（产品）、`免配置/master_sim`（工具与 CLI）、`免配置/configuration-free`  
**子站示例地址：** 192.168.0.10（运维 2405、103 数据 2404、61850 102）

## 1. 文档目的与适用范围

本文说明如何从《保信子站免配置技术方案》理解**主站侧需求**，并映射到本项目的**Windows 仿真主站**（**SimMasterQt** + `mms_master_cli` + SCDPro）实现与验收。

适用对象：联调工程师、测试人员、二次开发人员。

**不在本文范围：** 子站 C++ 业务修改、生产环境主站全套功能（抓包、召日志、程序升级等）的完整实现。

## 2. 术语与角色

| 术语 | 含义 |
|------|------|
| 子站 | 部署 `configuration-free` 的保信子站装置，本项目中为 192.168.0.10 |
| 运维主站 | 通过 **IEC 60870-5-104** 连接子站 **运维口（2405）**，下装台账/SMCD 并下发配置生效 |
| 业务主站（103） | 通过 103 规约（常经 104 承载）与子站交互运行数据，如总召、通断等；对应子站 **2404** 等 |
| 业务主站（61850） | 作为 **MMS 客户端** 连接子站 **102**，访问站模型与通信工况等 |
| IED / 保护装置 | SCD 中各间隔设备；实验室由 **SCDPro** 在 10.100.100.x:102 仿真 |
| 台账 | `IEDList.xml`，描述子站要接入的装置列表 |
| SMCD | 站级 61850 配置；下装形式为 `station.zip`（内含 `station.SMCD`） |

### 2.1 实验室拓扑中的「主站」

在闭环测试中，**一台 Windows 机**同时承担：

1. **运维主站** — 连接 192.168.0.10:2405  
2. **61850 业务主站** — 连接 192.168.0.10:102（读 `SubStation` 通信工况）  
3. **IED 仿真机** — SCDPro 加载 `26579.SCD`，在本机 10.100.100.x 监听 102  

子站负责：接收配置 → 启动 `iec61850router` → 作为 MMS 客户端连接各 IED → 作为 MMS 服务器对主站提供站模型。

## 3. 技术方案中的主站需求（摘要）

依据《保信子站免配置技术方案》，主站与子站关系可归纳为两层。

### 3.1 传输与角色

- 子站与主站采用 **TCP/IP**；**104 规约**负责链路（STARTDT、I/S/U 帧、序号确认等）。
- 在 104 上承载 **南网扩展 103 ASDU**（运维与部分业务）。
- **主站为 104 客户端，子站为 104 服务端**（运维口由主站主动连接）。

### 3.2 运维主站（免配置核心）

子站提供**独立运维通道**（本项目 **MaintainServer，端口 2405**），主站应支持：

| 能力 | 说明 |
|------|------|
| 文件下装 | 南网 103 文件传输（方案 ASDU 105～108；子站实现见 0x69/0x6B 等） |
| 配置生效 | 下装完成后下发「配置生效」；61850 配置对应 **生效类型 61850（INF=2）** |
| 扩展能力 | 网络抓包、召日志、程序/补丁更新等（仿真主站可不实现） |

**必须下装的两个文件：**

| 路径（逻辑） | 内容 |
|--------------|------|
| `/CONF/IEDList.xml` | 台账，装置接入参数 |
| `/SMCD/station.zip` | 压缩包根目录为 `station.SMCD`（体积大时用 zip） |

**配置生效后子站行为（61850）：** 根据台账与 SMCD 启动 **iec61850router**，建立对下 MMS 连接与对上 MMS 服务（默认 **102**）。

### 3.3 台账文件（方案 3.1）

- 文件名：**IEDList.xml**，XML 格式。  
- 每条 **61850 装置**（`p_type=1`）至少包含：  
  - `ied_name`：与 SCD 一致  
  - `ch_para`：`IP:端口`（如 `10.100.100.20:102`）  
  - `no`：序号，从 1 递增  
  - 报告控制、录波路径等默认属性（方案表内默认值）  
- **顺序要求：** `no` 及台账中 61850 装置顺序，须与 SMCD 内 **SubStation / LD0 / LN0** 下 **`dsCommState` 数据集 FCDA 顺序一致**。

### 3.4 SMCD 与 SubStation 模型

- SMCD 为站级 SCL，需包含 IED 名称 **`SubStation`**。  
- **LD0 / LN0** 下须有名称包含 **`dsCommState`** 的数据集，用于各装置通信工况（方案 3.3）。  
- 子站 `iec61850router` 会将其他 IED 的 LDevice 合并进 SubStation 并生成 CID（`genconfig.jar`），模型不完整会导致 102 无法启动。  
- 生成后的 **MMS 逻辑设备域** 为 **`SubStationLD0`**（`supervision.cfg` 中 `LD(SubStationLD0)`），与 SCL 中 inst=`LD0` 的写法并存，主站读点须用前者。  
- 现场 SMCD 中 `dsCommState` 的 **FCDA 多指向各装置 `LPHD1.Proxy`（fc=ST）**；语义上仍是「通信工况数据集」，不是另建一套与台账无关的测点。

### 3.5 业务主站（103 数据面，简述）

方案描述子站对主站还提供 **103 业务**（如总召 ASDU7、通断 ASDU42/ASDU1 等），与 **XJCommuServer103（2404）** 等相关。  

**仿真验收的侧重点**通常是：运维配置正确后，103/61850 链路能按台账工作；完整 103 主站功能非 `master_sim` 最小集。

### 3.6 业务主站（61850 数据面）

对应方案 §2「装置通信状态上送」：**总召/读通信工况控制块及数据集**，子站运行中状态变化由报告上送（子站实现细节以 `iec61850router` 为准）。

- 子站 **监听 102**，对外呈现 **SubStation** 合并站模型。  
- 主站（MMS 客户端）只连 **子站 192.168.0.10:102**，**不得**在闭环中对各 `ch_para` IED 分别读工况。  
- **标准 MMS 引用（唯一验收读点）：** `SubStationLD0/LLN0$dsCommState`。  
  - **禁止**使用 `LD0/LLN0$dsCommState`（合并模型代理分派下易失败）。  
  - **禁止**用「枚举全站 `LPHD1.Proxy`」代替对上述数据集的读取（无 FCDA 顺序、与方案 3.1 台账顺序不一致）。  
- 大 SMCD 冷启动：配置生效后 **102 监听常需约 8～15 分钟**；关联后应避免立即 `GetLogicalDeviceList` 或并发读多数据集。  
- 若全量 `readDataSetValues` 超时/断连，主站可按 **与下装一致的 `station.SMCD`** 解析 SubStation 段 `dsCommState` 的 FCDA 顺序逐点读 Proxy，**对外 ref 仍为 dsCommState**（实现标记 `source=smcd_fcda`）。  
- 验收：**关联成功**且读到 **条目数与 FCDA 一致** 的工况数组；未接保护网时 **多为「分」仍算读通**；不得以读失败却用 Proxy 扫全站冒充通过。

### 3.7 网络（IED 可达性）

- 子站根据 IEDList 访问 `ch_para` 中的 IP。  
- 实验室需：**本机**绑定 SCD 中 `10.100.100.x`，**子站**增加路由至本机（如 `10.100.100.0/24 via 192.168.0.27`）。  
- SCDPro 仿真模式参考其目录下 `multi_mms_config.ini`（`is_simulation=1`）。

## 4. 协议与报文对照（运维口）

**原则：** 方案中的 ASDU 编号与十六进制实现并存时，**以子站代码为准**。

| 业务 | 方案常见表述 | 子站实现（yn_maintain103） | 主站期望应答 |
|------|--------------|----------------------------|--------------|
| 下装文件信息 | ASDU 105 等 | 0x69 | 0x6A，COT=0x14 |
| 下装文件内容 | ASDU 106 等 | 0x6B | 0x6C（按帧确认策略） |
| 配置生效（61850） | ASDU 202，INF=2 | 0xCA，INF=2 | 0xCB，COT=0x14 |
| 104 帧格式 | IEC 60870-5-104 | **CMH_104_Len2_NoCpu**（2 字节长度域） | STARTDT 等 |

**运维流程（主站顺序）：**

1. TCP 连接 2405，交换 STARTDT。  
2. 下装 `/CONF/IEDList.xml`。  
3. 下装 `/SMCD/station.zip`。  
4. 发送 61850 配置生效（0xCA，INF=2）。  
5. 确认子站进程 `iec61850router` 及 **102 监听**（大 SMCD 冷启动常需 **8～15 分钟**；SMCD 未变可复用已有 cfg）。

**子站侧前置：** `MaintainServer.ini` 中 `p61850` 指向 `iec61850router` 绝对路径或保证 `PATH` 含 `~/router/bin`；`LD_LIBRARY_PATH` 含 router 库；已安装 `unzip`。

## 5. 仿真主站软件需求（SimMasterQt）

**唯一产品入口：** `sim_master_qt.exe`（运维/下装 Tab + 61850 主站 Tab）。  
Python `gui.py` / `run_lab.py` 为历史参考，**不再作为验收路径**。`build_config.py` 仅作 ConfigGenerator 对照。

三层边界见 [`master_sim/sim_master_qt/docs/MASTER_ARCHITECTURE.md`](master_sim/sim_master_qt/docs/MASTER_ARCHITECTURE.md)。

### 5.1 功能需求

| ID | 需求 | SimMasterQt 模块 | CLI / 工具 |
|----|------|------------------|------------|
| F1 | 从 SCD 解析 ConnectedAP，生成 IEDList.xml | `ConfigGenerator` | 可选 `build_config.py` 对照 |
| F2 | 生成含 SubStation/dsCommState 的 station.SMCD 及 station.zip | `ConfigGenerator` + `station_zip_writer` | 同上 |
| F3 | 104 运维客户端：下装两文件 + 61850 生效 | `Iec104MaintainClient` + `lab_operations::runUpload` | — |
| F4 | 一键：生成 + 下装 + 等 102 + 可选 MMS 探测 | `OpsDeployWidget` | — |
| F5 | 图形界面：参数、日志、端口探测 | `MasterSimShell`（运维 Tab） | — |
| F6 | 102 工况 / 订阅 / 数据集 / 录波 | `MmsClientBridge` + `MmsMasterWidget` | `mms_master_cli.exe` |
| F7 | 本机批量添加 10.100.100.x（管理员） | — | `add_sim_ips.ps1` |

### 5.2 非功能需求

- 产品为 Qt6 + `mms_master_cli`（libiec61850），不修改子站业务 C++。  
- 默认子站 IP：192.168.0.10；生成输出：`master_sim/out/` 或运维 Tab 所选目录。  
- 大文件下装：遵守子站每 N 帧确认策略（当前客户端默认每帧确认以保证可靠）。  
- 工况读点固定 `SubStationLD0/LLN0$dsCommState`；MMS 数据集优先，`source=smcd_fcda` 仅后备。  
- 验收脚本可设 `iedDataSetOnly`；**产品 UI 默认关闭**该开关。

## 6. 验收标准（建议）

1. **运维：** 2405 两次下装均肯定应答；装置上存在 `.../maintain/CONF/IEDList.xml` 与 `.../maintain/SMCD/station.SMCD`。  
2. **生效：** 0xCB COT=0x14；`iec61850router` 以 **`-d …/IEDList.xml -c …/station.SMCD`** 运行；**102 LISTEN**（大模型冷启动见 3.6）。  
3. **对下：** 子站能访问至少一台 `10.100.100.x:102`（SCDPro）。  
4. **对上 61850 工况：** 读 **`SubStationLD0/LLN0$dsCommState`** 成功（`comm_state`，日志含 `ref`/`source`）；通断值允许为分。`source` 优先为 `directory` 或 `dataset`，仅失败后才为 `smcd_fcda`。  
5. **103 工况（可选）：** ASDU7/ASDU42 等与方案 §2 103 节一致，**不与 61850 dsCommState 混判**。
